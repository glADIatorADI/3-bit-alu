# Hybrid 3-Bit ALU

A custom-engineered Arithmetic Logic Unit (ALU) that physically computes 4 distinct hardware-level arithmetic operations. This hybrid design merges foundational digital logic circuits with modern microcontroller I/O for real-time computation display.

**System Architecture & Hardware**
* **Core Logic:** Hardware computation powered by combinational logic gates, flip-flops, and dedicated ICs.
* **Interface & Control:** Arduino microcontroller (C++) handling user inputs and system state.
* **I/O Peripherals:** 16-key matrix keypad for binary inputs and an OLED display for immediate visual output of results.

**Impact & Recognition**
* Demonstrated 100% computation accuracy across all hardware arithmetic operations.
* Secured 1st place in the Intra Department Project-Based Learning curriculum.
